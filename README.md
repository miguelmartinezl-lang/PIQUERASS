# PIQUERASS

PIQUERASS es una aventura 3D de exploración rural para navegador, construida con Three.js. Esta primera versión es un juego funcional y autocontenido: puedes recorrer el pueblo, conducir, descubrir lugares, cambiar clima y hora, y guardar tu progreso localmente.

## Jugar localmente

Necesitas Node.js 20 o posterior.

```bash
npm install
npm run dev
